# Lab03RegistroProducto - Registro de Productos en Android

**Autor:** Jose  
**Curso:** Desarrollo de Aplicaciones Móviles  

## Descripción del Proyecto
Aplicación móvil desarrollada en **Jetpack Compose** que implementa un formulario interactivo para el registro de productos, validando datos de forma segura y calculando el importe total.

## Pregunta de Análisis
* **¿Qué pasaría si declaras las variables de los campos SIN `remember`?**  
Si quitas el remember, cada vez que escribas una letra la pantalla se redibuja y la variable se borra, haciendo que sea imposible escribir algo en el campo.
