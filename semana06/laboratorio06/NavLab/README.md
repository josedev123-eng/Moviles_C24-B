## Pantallas

| Pantalla | Descripción |
|---|---|
| **Inicio** | Título *Pantalla Tecsup* centrado y dos botones apilados de ancho completo: uno relleno para ver la lista y otro solo con borde para ir al perfil. |
| **Lista** | Barra superior con título y flecha para volver. Debajo hay una lista desplazable de 8 elementos separados por líneas, y cada uno abre su detalle al tocarlo. |
| **Detalle** | Barra superior con flecha para volver. Muestra el número del elemento elegido y una tarjeta con el ID recibido. |
| **Perfil** | Título *Mi Perfil*, el nombre del usuario y un botón para ir al inicio que limpia el historial. |
